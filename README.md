# St. Alphonsa Syro-Malabar Church, Nellyadi — Website

This folder contains the complete source code for the **St. Alphonsa Syro-Malabar Church, Nellyadi** website.

## Files
- `index.html`: The complete single-page responsive website incorporating Bootstrap 5, FontAwesome icons, Syro-Malabar liturgical styling, St. Thomas Forane structure, SMYM Nellyadi Instagram integration, and Google Maps location pin.

## How to Run Locally
1. Open the `website/` folder in your browser or code editor.
2. Double-click `index.html` to open it instantly in any web browser.

## How to Deploy / Host Free
- **Netlify / Vercel / GitHub Pages:** Simply drag and drop the `website/` folder into [Netlify Drop](https://drop.netlify.com/) or push it to a GitHub repository and enable GitHub Pages.
